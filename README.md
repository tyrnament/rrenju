# Рендзю для Android

Игра для двоих на одном телефоне: доска 19×19, чёрные и белые камни, правила рендзю с запретами для чёрных.
Язык — Kotlin, без внешних библиотек (только Android SDK).

## Как получить APK

**Вариант 1 — Android Studio.** `File → Open` → выбрать эту папку → дождаться синхронизации Gradle →
`Build → Build APK(s)`. Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.
Либо подключите телефон (отладка по USB) и нажмите ▶ Run.

**Вариант 2 — без установки Android Studio (GitHub Actions).** Создайте репозиторий на GitHub,
загрузите туда содержимое папки, откройте вкладку Actions → «Build APK» → скачайте артефакт `renju-debug-apk`.
Перед сборкой там же прогоняются тесты правил.

**Вариант 3 — командная строка.** Нужны JDK 17 и Android SDK (платформа 34):
`./gradlew assembleDebug`

Чтобы установить APK, на телефоне разрешите установку из неизвестных источников.

## Что реализовано

- Доска 19×19, камни, звёздные точки, координаты A–S / 1–19.
- Первый ход чёрных — строго в центр (ставится автоматически).
- Открытие: 2-й ход (белые) — зона 3×3 вокруг центра, 3-й ход (чёрные) — зона 5×5; зона подсвечена зелёным.
  После 3-го хода показывается напоминание: второй игрок выбирает цвет (может поменяться местами).
- Запреты для чёрных по правилам RIF: длинный ряд (6+), «четыре–четыре», «три–три»,
  включая исключения: ровно пять в ряд всегда выигрывает; «ложная» тройка (которую можно развить только запрещённым ходом) не считается.
- Запретные поля отмечены красными крестиками; ход туда отклоняется с объяснением причины.
  В настройках можно включить режим «запретный ход = поражение чёрных».
- Победа: чёрные — ровно пять, белые — пять и более. Выигрышный ряд подсвечивается. Ничья — поле заполнено.
- Отмена хода, новая партия, номера ходов на камнях, масштаб щипком и сдвиг доски, автосохранение партии.
- Подтверждение хода: выбрать пересечение → «Поставить» (или коснуться ещё раз); отключается в настройках.

Не реализовано: пятый ход с двумя предложениями (по полным правилам RIF), игра против компьютера, онлайн.

## Структура

- `Rules.kt` — доска и определение запретных ходов (чистый Kotlin, без Android).
- `Game.kt` — ход партии, открытие, победа, отмена, запись/восстановление.
- `BoardView.kt` — отрисовка и жесты. `MainActivity.kt` — экран, диалоги, настройки.
- `app/src/test/.../RenjuRulesTest.kt` — тесты правил (JUnit): `./gradlew testDebugUnitTest`.
